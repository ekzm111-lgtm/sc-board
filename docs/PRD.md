# 제품 요구사항 정의서 (PRD - Product Requirements Document)

## 1. 프로젝트 개요
- **프로젝트 명**: 학교용 패들릿 웹 애플리케이션 (School Board - 서귀포대신중학교 특화)
- **목적**: 기존 상용 Padlet의 비용 부담과 광고, 관리 통제 한계를 해결하고, 학교 교육 현장의 안전성·효율성·학습 몰입도를 극대화하는 맞춤형 협업 보드 플랫폼 구축.
- **핵심 가치**:
  1. 안전한 학교 전용 공간 (외부인 차단, 학급 분리)
  2. 교사의 수업 통제력 (보드 즉시 잠금, 승인 후 게시 기능)
  3. 초간편 접근성 (학생의 번거로운 가입 절차 없이 학교 구글 계정 매칭)
  4. 데이터 안정성 및 영속성 (클라우드 Supabase DB 기반, 로컬 캐시 유실 방지)

## 2. 사용자 역할 (User Roles & Permissions)

| 역할 | 권한 및 기능 범위 | 가입/식별 방식 |
|---|---|---|
| **슈퍼 관리자 (Admin)** | - 전체 사용자 및 교사 승인/반려 관리<br>- 학교 도메인 설정 및 학생 명단(CSV) 일괄 초대/등록<br>- 전체 보드/게시물 모니터링, 신고 내역 처리, 감사 로그 열람 | 시스템 초기 계정 및 교사 중 지정 |
| **교사 (Teacher)** | - 가입 신청 후 관리자 승인 시 교사 권한 획득<br>- 학급(Class) 개설 및 관리, 보드(Board) 무제한 생성<br>- 보드 설정: 공개 범위, 읽기 전용 잠금(Lock), 게시물 승인제 ON/OFF<br>- 학생 게시물 수정/삭제/고정/피드백 작성, 보드 내보내기(PDF/인쇄) | 구글 로그인 후 교사 권한 신청 -> 관리자 승인 |
| **학생 (Student)** | - 자가 회원가입 불가 (사전 등록된 학생만 로그인 가능)<br>- 배속된 학급의 보드 조회 및 포스트잇/게시물 작성<br>- 자신이 작성한 게시물/댓글만 수정 및 삭제 가능<br>- 부적절한 게시물 신고(Report) | 학교 구글 계정 로그인 시 초대 명단과 자동 매칭 |

## 3. 핵심 기능 요구사항

### 3.1. 사용자 및 학급 관리
- **학생 사전 초대제**:
  - 교사/관리자가 학생 명단(학번, 이름, 구글 이메일)을 업로드/등록.
  - 학생이 학교 구글 계정(`@daeshin.ms.kr` 등)으로 로그인 시 초대 명단과 대조하여 자동으로 학생 프로필 생성 및 학급 배정.
  - 사전 등록되지 않은 임의의 외부 계정은 로그인 차단.
- **교사 승인제**:
  - 교사로 가입 신청 시 승인 대기 상태(`approved = false`)로 전환.
  - 관리자가 승인하기 전까지는 보드 생성 불가 (안내 화면 표시).

### 3.2. 보드(패들릿) 코어 기능
- **다양한 레이아웃**:
  - **그리드/월 (Wall)**: 카드들이 빈틈없이 차곡차곡 정렬.
  - **열/컬럼 (Shelf/Column)**: 모둠별, 주제별, 단계별 컬럼 분류.
  - **자유 캔버스 (Canvas)**: 원하는 위치에 자유롭게 배치 및 드래그 이동.
- **게시물(포스트) 생성 및 편집**:
  - 텍스트(마크다운 지원), 배경색(파스텔톤 5종), 태그 지원.
  - **단일 통합 첨부 (`attachments`)**:
    - **사진/이미지**: 브라우저 Canvas 레벨에서 1600px / 80% 압축(300KB 이하) 후 Supabase Storage 업로드.
    - **파일**: 문서/PDF/학습지 업로드 (용량 제한 적용).
    - **웹 링크**: URL 입력 시 오픈그래프(OG) 메타데이터 미리보기 카드 생성.
    - **유튜브**: 유튜브 링크 입력 시 임베드 플레이어 렌더링.
- **실시간 상호작용 (Realtime Collaboration)**:
  - Supabase Realtime을 통한 실시간 새 글, 수정, 삭제 동기화.
  - 좋아요(반응) 및 댓글(Comment) 기능 (교사가 켜고 끌 수 있음).
- **수업 통제 도구 (교사 필수)**:
  - **보드 읽기 전용 잠금 (Lock)**: 수업 마감 시 버튼 하나로 전체 학생 쓰기 차단.
  - **게시물 승인제 (Moderation)**: 학생이 작성한 글을 교사가 승인해야 전체 학생에게 보임.

### 3.3. 안전 및 감사 (Safety & Audit)
- **신고 시스템**: 학생들이 욕설, 비방, 음란물 등 부적절한 글 발견 시 신고 -> 교사/관리자 대시보드에 즉시 경고 표시 및 비공개 처리 지원.
- **감사 로그 (Audit Log)**: 글 삭제, 잠금 변경, 권한 변경 등의 주요 이력을 기록.

## 4. 비기능적 요구사항 (Non-functional Requirements)
1. **무료 플랜 최적화**: 신용카드 없이 사용 가능한 Supabase 무료 티어(500MB DB, 1GB Storage) 한도 내에서 장기간 운영할 수 있도록 이미지 클라이언트 압축을 의무화.
2. **반응형 웹**: 모바일(스마트폰), 태블릿(아이패드, 갤럭시탭, 크롬북), PC 데스크톱 완벽 지원.
3. **네트워크 탄력성**: 학교 무선망의 일시적 끊김 발생 시 사용자 작성 글이 날아가지 않도록 입력 중 임시 캐싱 지원.

- 서드파티 복잡한 플러그인 생태계 (핵심 교육 기능에 집중)
