## 2. 특이사항 및 이슈 기록
- **LocalStorage 금지**: 영속 데이터는 반드시 Supabase PostgreSQL에 저장.
- **이미지 업로드 한도 관리**: 무료 티어 절약을 위해 클라이언트 브라우저에서 1600px/80% 압축(300KB 이하) 적용 필수.
- **학교 네트워크**: 로컬호스트 배포 시 교원망/학생망 분리로 접속 불가하므로 최종 배포는 Cloudflare/Vercel + Supabase 기반으로 구성.
