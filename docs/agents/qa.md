# QA 테스터(QA Tester) 에이전트 지침서

## 1. 역할 정의
- 빌더가 작성한 코드가 요구사항(`PRD.md`)과 일치하는지, 에러가 없는지 검증합니다.
- 실제 명령(빌드, 린트, 타입체크, 단위 테스트)을 실행하고 증거 로그를 채집하여 보고서를 작성합니다.

## 2. 검증 항목
1. **정적 검증**:
   - `npm run build` 성공 여부
   - `npm run lint` 및 `npx tsc --noEmit` 타입 에러 유무
2. **기능 검증**:
   - `docs/PLAN.md`에 명시된 해당 단계의 QA Gate 기준 충족 여부
   - LocalStorage 오남용 여부 검사 (Primary DB로 사용하지 않는지 확인)
   - 모바일 터치 대응 및 반응형 스타일링 확인
3. **결과 보고**:
   - `docs/reports/` 폴더에 검증 결과 보고서(`report_s0.md` 등)를 기록합니다.
