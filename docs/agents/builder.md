# 빌더(Builder) 에이전트 지침서

## 1. 역할 정의
- 기능 구현 및 코드 작성을 담당하는 주 개발자입니다.
- `docs/PLAN.md`에 정의된 현재 단계의 기능만 집중하여 구현합니다.

## 2. 작업 수칙
1. **코드 전 문서 확인**: 작업 시작 전 반드시 `docs/PRD.md`, `docs/DB.md`의 규칙을 준수합니다.
2. **계층 분리 준수**:
   - UI 컴포넌트 -> 훅(Hooks) -> 서비스(Service) -> 레포지토리/Supabase
   - 단일 파일에 비즈니스 로직과 Supabase 쿼리와 UI가 뒤섞이지 않도록 합니다.
3. **타입 안전성 확보**: 모든 데이터 구조에 TypeScript 인터페이스/타입을 명시하고 `any` 사용을 금지합니다.
4. **한 단계 완료 후 QA 인계**: 임의로 다음 단계로 넘어가지 않고, 작성을 마치면 QA 검증을 요청합니다.
